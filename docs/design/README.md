# Макеты экранов

Черновые макеты из холста «Бегуны — макеты ключевых экранов» (Claude Design).
Файлы `.dc.html` — разметка экранов: ориентир по логике, составу и компоновке, а не по пикселям.
Имена, цифры и даты в них условные. Цвет-акцент #C2410C, шрифт Inter.

| Файл | Экран | Изменение |
|---|---|---|
| Main.dc.html | Главная, телефон: карта с линиями треков, фильтр дистанции, выдвижной список | add-map-search |
| DesktopMain.dc.html | Главная, десктоп: список слева, карта справа | add-map-search |
| Card.dc.html | Карточка трека, телефон: маршрут, показатели, GPX, таблица группы | add-map-search, add-route-matching |
| DesktopCard.dc.html | Карточка трека, десктоп: панель слева, маршрут на карте с отметками км | add-map-search, add-route-matching |
| Processing.dc.html | Загрузка: шаги обработки | add-track-upload |
| Preview.dc.html | Превью: скрытая зона, плашка совпадения, форма, видимость | add-track-upload, add-route-matching |
| ResultWin.dc.html | Результат: превзошёл | add-achievements |
| ResultSlower.dc.html | Результат: медленнее (блок сплитов — по решению, см. ниже) | add-achievements |
| CheckFail.dc.html | «Проверить мою пробежку»: маршрут не совпал | add-route-matching |

Блок «Где ушло время» на экране «медленнее» использует сравнение сплитов (ФТ-22, этап 2);
в MVP его не делать, пока не решено иначе.
Пустого состояния карты нет — решено не делать отдельный экран.
