# Сценарии показа

Стенд: `http://<demo-host>:8088` (адрес — у владельца стенда). Вход — «Вход для разработки» (email + имя, без пароля).
Лимит — 20 загрузок в час на бегуна: для каждого сценария удобно заводить нового бегуна
(`demo1@example.com`, `demo2@example.com`…).

## 1. Живой показ: новый маршрут → не превзошёл → превзошёл

Файлы: `tracks-demo/live/` (маршрут, которого нет в дампе).

1. Войти новым бегуном, например `author@example.com` / «Автор».
   «Загрузить» → `1_novyj_marshrut.gpx` → в превью плашки совпадения нет → «Опубликовать»
   (видимость «Публичный»). Появился новый маршрут.
2. «Выйти» → войти вторым бегуном, например `guest@example.com` / «Гость».
   Загрузить `2_ne_prevzoshel.gpx` → плашка **«Совпало с маршрутом… — на 2:05 медленнее
   автора»** → «Опубликовать» → «Попытка засчитана», место 2.
3. Тем же бегуном загрузить `3_prevzoshel.gpx` → плашка **«на 1:31 быстрее автора»** →
   «Опубликовать» → ачивка «Превзошёл», место 1. В таблице группы у гостя «лучшая из 2».
4. Снова войти автором → в шапке значок **«2»** новых попытки; в «Моих треках» у маршрута
   «+2 новые» → открыть маршрут → таблица: гость первый, «превзошёл»; значок пропадает.

## 3. Карта и фильтры

Главная → линии маршрутов; отдалить — кластеры с числом треков. Дистанция «10» → только 7,5–15 км;
«Своя» сбрасывает категорию. «Новые» — опубликованные за последние дни; «Есть попытки».
Клик по линии — карточка с таблицей группы; клик в пустое место — снова список.

## 4. «Проверить мою пробежку» — почему не засчиталось

Бегун с загруженной `06_3km…/20261028` → открыть «Трёшка в одну сторону» → «Проверить мою
пробежку» → выбрать её → «похоже, маршрут пробежан в обратную сторону», правила с галочками,
на карте коридор и ваша линия. Засчитанная на этот маршрут пробежка помечена
«✓ Уже засчитана на этот маршрут».

## 5. Приватность: скрытая зона у дома

«Настройки» → дом («Моё местоположение» или координаты), радиус 300–500 м → «Сохранить».
Загрузить пробежку от дома → в превью начало и конец затенены. Открыть трек гостем в другом окне —
линия начинается за границей круга (с небольшим случайным запасом).

## 6. «Не засчитывать» и приватные треки

Загрузить совпадающую пробежку → в плашке «Не засчитывать» → опубликовать: трек обычный, в группу
не попал (как «Пятёрка без зачёта» Кирилла). Видимость «Приватный» — плашки нет: приватные и
«по ссылке» не сопоставляются.

## 7. Рейтинги

«Рейтинги» → вкладки 1/5/10/21/21+. Популярность = 5 × бегуны группы + 2 × скачивания GPX,
пересчёт раз в час.

## Обслуживание стенда

```bash
# пересобрать дамп (если меняли сценарий) и выкатить код
python3 -I tools/make_demo_dump.py tracks tracks-demo
SSH_KEY=<ключ> WEB_PORT=8088 deploy/deploy_demo.sh root@<demo-host>

# чистая база: на сервере
cd /opt/runners && C="docker compose -p runners-demo -f docker-compose.demo.yml --env-file deploy/demo.env"
$C down -v && $C up -d --wait
# загрузка дампа (локально)
cd backend && uv run python ../tools/load_dump.py ../tracks-demo http://<demo-host>:8088/api
# на сервере: даты публикации = даты пробежек (фильтр «Новые»), пересчёт рейтингов
$C exec -T postgres sh -c 'psql -U $POSTGRES_USER $POSTGRES_DB -c "UPDATE tracks SET published_at = started_at + interval '"'"'2 hours'"'"' WHERE published_at IS NOT NULL"'
$C exec -T api python -c "from app.infra.tasks import recalc_popularity_task as t; print(t())"
```

Резервная копия базы до загрузки этого дампа: `/opt/runners-backup/` на сервере.
Вход через Google на стенде недоступен — нет Client ID.
