# Рабочие кейсы для показа

Сценарии на реальных данных (ваши пробежки во Владивостоке и тестовый дамп), проверенные на
локальном стеке 14.11.2026. Для каждого: что делать, что увидит зал, что это показывает.

## Подготовка (один раз, ~5 минут)

```bash
docker compose up -d --build --wait                              # стек
cd backend && uv run python ../tools/load_dump.py ../tracks-dump # дамп: 31 трек, 6 бегунов
docker compose exec api python -m app.scripts.rematch_all        # разложить по группам
docker compose exec api python -c "from app.infra.tasks import recalc_popularity_task as t; print(t.delay().get())"
```

- Открывайте http://localhost:5173 в **окне инкогнито** — тогда сработает вопрос «Показать
  треки рядом с вами?» (кейс 1).
- Вход — «Вход для разработки» (email + имя). Для каждого кейса удобно заводить нового бегуна:
  `demo1@example.com`, `demo2@example.com`… Один и тот же файл одному бегуну дважды не загрузить
  («Этот трек уже есть») — это тоже можно показать.
- Бегуны дампа (вход с их email и именем): `marina@example.com` — «Марина В.»,
  `oleg@example.com` — «Олег Т.», `sergey@…` — «Сергей Н.», `anna@…` — «Анна Л.»,
  `kirill@…` — «Кирилл Д.», `polina@…` — «Полина Р.».
- Файлы — из `tracks/` (разложены по сериям, см. `tracks/README.md`).

## 1. Карта маршрутов рядом
1. Главная → «Показать треки рядом с вами?» → «Не сейчас» (или «Показать», если вы во Владивостоке).
2. Отдалить карту — линии собираются в кластеры с числом треков; приблизить — снова линии.
3. Дистанция «10» → в списке только 7,5–15 км; «Своя» → категория сбрасывается, свой диапазон.
4. «Новые», «Есть попытки»; «Скрыть фильтры» на телефоне; «Сбросить».

**Показывает:** ФТ-10–14, фильтр дистанции первым, состояние карты в адресе (ссылкой можно поделиться).

## 2. Загрузил пробежку — превзошёл автора
1. Новый бегун → «Загрузить» → `tracks/04_10km_2-probezhki/20260629….gpx`.
2. Шаги обработки (~1–2 с) → превью: плашка **«Совпало с маршрутом „Большая десятка“ —
   на 2:24 быстрее автора»**, «вырезан участок маршрута 10,0 км из 10,2».
3. «Опубликовать» → экран результата: **ачивка «Превзошёл»**, «−2:24», место в группе.
4. «Вся группа маршрута» → таблица: несколько бегунов, отметки «превзошёл», «автор», «Вы».

**Показывает:** главную механику продукта — соревнование без «вызовов», сразу из загрузки (сценарии А и Б).

## 3. Медленнее автора
1. Новый бегун → загрузить `tracks/01_5km_3-probezhki/20250529….gpx`.
2. Плашка: совпало с «Пятёркой у дома» (Олег Т.), на 2 с медленнее; пометка «у автора скрыто
   начало или конец маршрута — добавлено 8:53 по вашему темпу».
3. «Опубликовать» → «Попытка засчитана», «+2 с — столько не хватило до автора», место.

**Показывает:** сравнение по общему времени; досчёт скрытой зоны автора (раздел 5.1).
⚠️ Если зал спросит про «8:53»: у автора короткое кольцо от дома, скрыта большая доля маршрута,
поэтому вклад оценки велик — известная особенность правила ТЗ.

## 4. Автор видит новые попытки
1. Выйти, войти как `oleg@example.com` / «Олег Т.».
2. На «Профиле» — значок с числом новых попыток; в «Моих треках» у маршрута «+N новые».
3. Открыть маршрут → таблица группы → значок пропадает.

**Показывает:** сценарий В в MVP (счётчик вместо уведомлений).
Перед показом убедитесь, что на маршрут Олега пришла свежая попытка (кейс 3 её создаёт).

## 5. «Проверить мою пробежку» — почему не засчиталось
1. Новый бегун → загрузить `tracks/06_3km_2-probezhki_linejnyj/20261028….gpx` (можно не публиковать).
2. Открыть маршрут «Трёшка в одну сторону» → «Проверить мою пробежку» → выбрать пробежку 28 октября.
3. «Маршрут не совпал: похоже, маршрут пробежан в обратную сторону», правила с галочками и
   крестиками, на карте — коридор 30 м и ваша линия.

**Показывает:** ФТ-19 — система объясняет решение, а не просто отказывает. Пробежка, уже
засчитанная на этот маршрут, помечена «✓ Уже засчитана на этот маршрут».

## 6. Приватность: скрытая зона у дома
1. Бегун → «Настройки» → широта/долгота дома (или «Моё местоположение»), радиус 300 м → «Сохранить».
2. Загрузить пробежку, стартующую у дома → в превью начало затенено кругом.
3. Открыть тот же трек гостем (другое окно) → линия начинается за границей круга.

**Показывает:** ФТ-4 — реальные координаты дома не уходят другим.

## 7. «Не засчитывать» и приватные треки
1. Загрузить пробежку, совпадающую с маршрутом → в плашке «Не засчитывать» → опубликовать:
   трек обычный, в группу не попал.
2. Либо выбрать видимость «Приватный» — плашка исчезает: приватные не сопоставляются.

**Показывает:** ФТ-18, правило «приватные и „по ссылке“ — вне групп».

## 8. Рейтинги
«Рейтинги» → вкладки 1/5/10/21/21+ → «Большая десятка» вверху 10 км.
Популярность = 5 × бегуны группы + 2 × скачивания GPX; пересчёт раз в час
(для показа — вручную, команда в «Подготовке»). «Скачать GPX» в карточке маршрута → после
пересчёта +2.

**Показывает:** ФТ-27–28.

## Особенности данных, о которых стоит знать заранее
- **«Пятёрка со срезкой».** Маршрутом группы стал вариант со срезкой (4,8 км) — он был
  опубликован первым. Поэтому полные «пятёрки» засчитываются на него с обрезкой хвоста, а пример
  «срезка не засчитывается» на живых данных не показать (он есть в автотестах).
- **Одинаковые имена.** В базе есть несколько бегунов «Пётр Тестов», «Ночной Бегун»,
  «Быстрая Вера» — следы проверок; можно не обращать внимания или начать с чистой базы.
- **Чистая база:** `docker compose down -v && docker compose up -d --build --wait`, затем шаги
  «Подготовки» (ваши собственные загрузки при этом тоже удалятся).
- **Вход через Google** на показе недоступен — нет Client ID (см. README, «Отложено до запуска»).
