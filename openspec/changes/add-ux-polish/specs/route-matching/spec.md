## ADDED Requirements
### Requirement: Check Shows Existing Attempt
Экран «Проверить мою пробежку» SHALL помечать пробежки, уже засчитанные попыткой на этот маршрут (и на другие маршруты), и показывать это в результате проверки.

#### Scenario: Already counted
- **WHEN** бегун выбирает для проверки пробежку, уже засчитанную на этот маршрут
- **THEN** она помечена в списке и стоит первой, а в результате написано «Уже засчитана в группе этого маршрута»
