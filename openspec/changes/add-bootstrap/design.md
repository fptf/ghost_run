## Context
Трёхзвенная архитектура из раздела 9 ТЗ, стек зафиксирован в `openspec/project.md`.

## Decisions
- Монорепозиторий: агенту проще держать фронт, бэк и спеки в одном контексте.
- Таблица `settings` (key, value jsonb) с первого дня: пороги сопоставления,
  границы категорий и коэффициенты популярности меняются без деплоя.
- Celery-воркер — отдельный контейнер с тем же образом, что api.

## Risks
- PostGIS в CI: использовать образ `postgis/postgis` в сервисе GitHub Actions.
