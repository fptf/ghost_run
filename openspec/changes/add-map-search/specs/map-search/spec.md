## ADDED Requirements
### Requirement: Map Display
Карта SHALL показывать публичные исходные и обычные треки линиями в обычном масштабе и кластерами только в мелком масштабе; попытки на карте MUST NOT показываться отдельно.

#### Scenario: Close zoom
- **WHEN** масштаб карты крупнее порога кластеризации
- **THEN** каждый подходящий трек показан линией

#### Scenario: City-wide zoom
- **WHEN** масштаб мельче порога
- **THEN** треки показаны кластерами с числом треков

#### Scenario: Attempts hidden
- **WHEN** у исходного трека есть 5 попыток
- **THEN** на карте показан только исходный трек

### Requirement: Distance Filter
Фильтр по дистанции SHALL быть первым и всегда видимым; он принимает категорию или произвольный диапазон км.

#### Scenario: Category 5 km
- **WHEN** бегун выбирает категорию 5 км в области карты
- **THEN** возвращаются только треки длиной от 3 до 7,5 км

### Requirement: Live Results
Результаты SHALL обновляться при сдвиге и масштабировании карты без перезагрузки страницы.

#### Scenario: Pan map
- **WHEN** бегун сдвигает карту
- **THEN** список и линии обновляются под новую область

### Requirement: Search Performance
Поиск по области карты с фильтрами MUST отвечать не дольше 500 мс при 1 млн треков.

#### Scenario: Load test
- **WHEN** в базе 1 млн треков и выполняется поиск по области с фильтром дистанции
- **THEN** p95 времени ответа не больше 500 мс

### Requirement: Track Card
Карточка трека SHALL показывать маршрут без скрытых зон, показатели, график темпа, автора и таблицу группы, и давать скачать маршрут в GPX.

#### Scenario: Download GPX
- **WHEN** бегун нажимает «Скачать GPX»
- **THEN** он получает GPX видимой части маршрута без точек из скрытых зон автора
