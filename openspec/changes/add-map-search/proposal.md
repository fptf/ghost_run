## Why
Сценарий Б начинается с поиска маршрута на карте. Фильтр дистанции — главный инструмент.

## What Changes
- Карта публичных исходных и обычных треков: линии в обычном масштабе, кластеры только
  в мелком (город целиком и дальше); попытки на карте не показываются (ФТ-10).
- Фильтр дистанции первым и всегда видимым; время, темп, дата, «есть попытки» (ФТ-11).
- Список с сортировкой (ФТ-12), текстовый поиск (ФТ-13), обновление при сдвиге карты (ФТ-14).
- Карточка трека: маршрут без скрытых зон, показатели, график темпа, скачивание GPX (ФТ-16).
- Адаптивная вёрстка: на телефоне выдвижной список снизу, на десктопе панель слева.

## Impact
- Affected specs: map-search (новая)
- Affected code: API поиска, экраны главной и карточки
- Макеты: docs/design/README.md
