## Why
Сценарий Б начинается с поиска маршрута на карте. Фильтр дистанции — главный инструмент.

## What Changes
- Карта опубликованных публичных исходных и обычных треков: линии в обычном масштабе, кластеры
  в мелком; попытки не показываются (ФТ-10). Стартовая область — Владивосток.
- Фильтр дистанции первым и всегда видимым; время, темп, дата, «есть попытки» (ФТ-11).
- Список с сортировкой (ФТ-12), текстовый поиск (ФТ-13), обновление при сдвиге карты и
  состояние в адресе страницы (ФТ-14).
- Карточка трека: маршрут без скрытых зон с отметками км, показатели, график темпа,
  скачивание GPX с учётом скачиваний (ФТ-16), «Показать на карте».
- Навигация по макетам: нижняя панель на телефоне, верхнее меню на десктопе.
- Настройки профиля сохраняются как трек: «Назад», после сохранения — в профиль.
- Требование «поиск ≤ 500 мс на 1 млн треков» (раздел 8 ТЗ) отложено: прототип
  (решение 13.11.2026); индексы закладываются сразу.

## Impact
- Affected specs: map-search (новая), profile (дополнение)
- Affected code: API поиска и GPX, треки (`parent_track_id`, скачивания), главная, карточка,
  навигация, настройки
- Макеты: docs/design/README.md (Main, DesktopMain, Card, DesktopCard)
