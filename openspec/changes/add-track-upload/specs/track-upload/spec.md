## ADDED Requirements
### Requirement: Supported Files
Система SHALL принимать файлы GPX, TCX и FIT размером до 20 МБ и обрабатывать их асинхронно.

#### Scenario: Valid GPX
- **WHEN** бегун загружает корректный GPX-файл
- **THEN** трек получает статус processing, а затем ready с рассчитанными показателями
- **AND** дистанция отличается от рассчитанной по точкам файла не более чем на 1%

#### Scenario: File too large
- **WHEN** бегун загружает файл больше 20 МБ
- **THEN** загрузка отклоняется до обработки с причиной «файл больше 20 МБ»

### Requirement: Track Metrics
Система SHALL рассчитывать дистанцию, общее время, время движения, средний темп, сплиты по километрам, набор высоты и категорию дистанции.

#### Scenario: Category assigned
- **WHEN** обработан трек длиной 5,2 км
- **THEN** ему присвоена категория 5 км по границам из настроек

### Requirement: Implausible Tracks Rejected
Система MUST отклонять файлы без отметок времени и треки со средним темпом быстрее 2:30 мин/км, сообщая причину.

#### Scenario: No timestamps
- **WHEN** в файле нет отметок времени
- **THEN** трек получает статус rejected с причиной «в файле нет времени»

#### Scenario: Too fast
- **WHEN** средний темп трека 2:10 мин/км
- **THEN** трек получает статус rejected с причиной «похоже на транспорт»

### Requirement: Duplicate Detection
Система SHALL распознавать повторную загрузку того же файла тем же пользователем.

#### Scenario: Same file again
- **WHEN** бегун загружает файл, который уже загружал
- **THEN** новый трек не создаётся, бегун получает ссылку на существующий

### Requirement: Home Privacy Zones
Система MUST хранить трек целиком, но отдавать другим пользователям только участки вне скрытой зоны автора и сохранять границы видимой части.

#### Scenario: Start inside zone
- **WHEN** трек начинается в 150 м от дома при радиусе зоны 300 м
- **THEN** публичная геометрия начинается в точке выхода трека из зоны
- **AND** API для других пользователей не содержит ни одной точки внутри зоны

#### Scenario: Owner preview
- **WHEN** автор открывает превью своего трека
- **THEN** он видит весь трек и затенённую скрытую зону

### Requirement: Visibility
Трек SHALL иметь видимость public, link или private; на карте и в поиске появляются только public.

#### Scenario: Private track
- **WHEN** бегун публикует трек с видимостью private
- **THEN** трек не появляется на карте, в поиске и в группах

### Requirement: Upload Rate Limit
Система MUST ограничивать загрузку 20 файлами в час на пользователя.

#### Scenario: Limit exceeded
- **WHEN** бегун загружает 21-й файл за час
- **THEN** загрузка отклоняется с указанием, когда можно продолжить
