# Design

- Контракт API — инвариант: после каждого шага `openapi.json` и сгенерированный клиент не
  меняются (проверяет `tests/test_ci.py`).
- Бэкенд и фронтенд дочищаются независимо: изменения не пересекаются по файлам.
- Тест «модели = миграции»: `alembic` autogenerate-сравнение (`compare_metadata`) на
  мигрированной БД должно давать пустой diff (с исключением служебных таблиц PostGIS).
- Каждый шаг — отдельный коммит; после шага зелёные тесты и линтеры.
