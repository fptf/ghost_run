# Бегуны — правила для Claude Code

## Источники
- Требования — `docs/tz.md` (ТЗ, разделы 1–11).
- Контекст, стек, архитектура, термины — `docs/project.md`.
- Макеты экранов — `docs/design/` (ориентир по логике и компоновке, не по пикселям).
- Отложенные идеи — `Бегуны идеи на потом.md` (только для справки, не реализовывать).

## Как работаем
- Только через изменения OpenSpec (`openspec/changes/<id>`). Порядок изменений — в `README.md`.
- Одно изменение = ветка `change/<id>`; выполненные задачи отмечаются в `tasks.md`.
- Архивировать изменение только после проверки человеком.
- Conventional Commits.

## Качество
- Каждый Scenario спеки покрыт минимум одним автотестом.
- CI (тесты + линтеры) должен быть зелёным; красный CI не мержится.

## Чего не делать
- Не реализовывать идеи вне ТЗ: рейтинги без привязки к маршруту, сегменты, монетизацию.
- Не менять зафиксированный стек (см. `docs/project.md`).
